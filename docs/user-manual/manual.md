## Owners

Use Owners to find and maintain client contact details. Each owner's record also brings together their pets and the pets' visits.

### Viewing the list

![](screenshots/owners-list.png)

Open Owners in the navigation bar to see the client list. Enter a name, address, city, telephone number, or pet name in Filter to narrow the results. Click an owner's name to open their record, or choose Add Owner to register someone new.

### Creating a new owner

![](screenshots/owners-create.png)

From the owners list, click Add Owner, enter the owner's name and contact details, then click Add Owner to save. The new owner's record opens after saving; choose Back to leave the form without saving.

### Looking at an owner's record

![](screenshots/owners-detail.png)

The record shows the owner's contact details, pets, and visits. Use Filter pets and visits to narrow the pet information, click Edit Owner to update the contact details, or choose Add New Pet to add a pet to this owner.

### Editing an owner

![](screenshots/owners-edit.png)

From an owner's record, click Edit Owner. The form is filled with the current details; make your changes and click Update Owner to save them, or choose Back to return without saving.

## Pets

Pet records are managed from an owner's page rather than from a separate pet list. Each pet entry shows the pet's name, birth date, type, and visit history. To find a pet, first locate its owner in [Owners](#owners).

### Viewing a pet and its visits

![](screenshots/pets-record.png)

Open the owner's record and find the pet under Pets and Visits. The entry includes the pet's basic details and its visit history; use the buttons beside the pet to edit it or add a visit.

### Adding a pet

![](screenshots/pets-add.png)

On the owner's record, click Add New Pet. Enter the pet's name and birth date, select a pet type, and click Save Pet. The pet is added to that owner's record.

### Editing a pet

![](screenshots/pets-edit.png)

On the owner's record, click Edit Pet beside the pet you want to update. Change the name, birth date, or type, then click Update Pet to save; choose Back to return to the owner's record without saving.

## Visits

Use Visits to review appointments across the clinic. You can add a visit from the relevant pet's record, where the owner and pet are already identified.

### Viewing the list

![](screenshots/visits-list.png)

Open Visits in the navigation bar to see visits with their dates, descriptions, pets, and owners. Enter a date, description, pet name, or owner name in Filter to narrow the list. Click an owner's name to open that owner's record.

### Adding a visit

![](screenshots/visits-add.png)

Open the owner's record, find the pet, and click Add Visit. Check the pet details shown above the form, enter the visit date and description, then click Add Visit. The visit is saved to the pet's history and you return to the owner's record.

### Editing a visit

![](screenshots/visits-edit.png)

In the pet's visit history, click Edit Visit beside the visit you want to change. Update the date or description and click Update Visit to save; choose Back to leave the form without saving.

## Pet Types

Pet Types is the clinic's list of types available when staff add or edit a pet. You can search the list, add a type, or update an existing one.

### Viewing the list

![](screenshots/pettypes-list.png)

Open Pet Types in the navigation bar. Enter a type name in Filter to narrow the list; use the row's Edit button to change a type, or Add to create one.

### Creating a new pet type

![](screenshots/pettypes-add.png)

Choose Add from the Pet Types list, enter the new type's name, and click Save. The new type will be available when you add or edit a pet.

### Editing a pet type

![](screenshots/pettypes-edit.png)

Click Edit beside the type you want to change. The current name is shown in the form; update it and click Update to save, or choose Cancel to return to the list without saving.

## Veterinarians

Use the veterinarian list to review staff names and specialties. You can add a veterinarian or edit an existing veterinarian's details and specialties.

### Viewing the list

![](screenshots/vets-list.png)

Open Veterinarians in the top navigation and choose All. Use Filter to search by veterinarian name or specialty. Click Edit Vet beside a veterinarian to update their record, or choose Add Vet to create one.

### Creating a new veterinarian

![](screenshots/vets-add.png)

Choose Add New from the Veterinarians menu or Add Vet from the list. Enter the veterinarian's first and last names, choose a specialty if applicable, and click Save Vet. Choose Back to return to the list without saving.

### Editing a veterinarian

![](screenshots/vets-edit.png)

Click Edit Vet beside the veterinarian. Their current name and specialties are selected in the form; make your changes and click Save Vet. Choose Back to return to the list without saving.

---

## Specialties

Use Specialties to maintain the clinic's list of veterinary specialties. These names can be assigned to veterinarians.

### Viewing the list

![](screenshots/specialties-list.png)

Open Specialties in the navigation bar. Enter a name in Filter to narrow the list; click Edit beside a specialty to update it, or choose Add to create a specialty.

### Creating a new specialty

![](screenshots/specialties-add.png)

Choose Add from the Specialties list, enter the specialty name, and click Save. The new specialty is then available for veterinarians.

### Editing a specialty

![](screenshots/specialties-edit.png)

Click Edit beside the specialty you want to change. Update its name or description and click Update to save, or choose Cancel to return to the list without saving.
